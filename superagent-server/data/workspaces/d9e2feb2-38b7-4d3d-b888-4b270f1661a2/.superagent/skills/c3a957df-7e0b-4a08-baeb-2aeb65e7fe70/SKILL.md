# 画图规范（设计师）

> 绘制流程图、架构图、信息图、配图或给出视觉设计方案时使用。

## 原则
- 一张图只讲一个结论，标题就写这个结论。
- 从左到右或从上到下单向阅读，避免交叉连线。
- 同一张图最多 3 种颜色：主色表示重点，灰色表示背景信息，红色只用于风险或错误。

## 规格
- 字体：中文用思源黑体 / 苹方，英文用 Inter；最小字号 12px。
- 留白：元素间距不小于 16px，画布四周留 32px。
- 形状：流程节点用圆角矩形，判断用菱形，数据存储用圆柱。
- 导出：PNG 2 倍图；需要编辑的同时给 SVG 或 Mermaid 源码。

## 交付
给出图的同时，用 2～3 句话说明图要表达的结论和阅读顺序。
可以在这里放参考图：在 Skill 页面上传图片后，用 `![说明](images/文件名.png)` 引用。
