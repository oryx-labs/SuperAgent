# 行动营作者 的记忆

## 目标与项目
- 正在写「DeepSeek Super Agent 行动营」课程（共 16 节，按四周安排）。素材放在知识库 `DeepSeek Super Agent 行动营/` 文件夹。
- 课程定位：参考 DeepSeek 原文做架构探索，不是官方课程。
- 第一周最终要交出能指导实现的设计；第 02 节要把「做一个 SuperAgent」收窄成第一版的产品定义。
- 第一节只讲概念和判断，不写代码。内容依次是：
  - 先抛出八个问题：任务来源、谁来执行、能访问什么、怎么隔离、怎么恢复、花了多少、谁来验收、结果怎么留存。
  - 再讲三类系统：个人助手、长任务执行器、企业工作平台。
  - 从 DeepSeek 原文的四个目标（连续、高效、主动、持久）倒推出 Router/Worker、事件过滤、异步、Watchdog。
  - 最后把八个问题对应到四层（入口、控制面、Router、Worker），这张表同时就是四周的路线图。
- 第一节作业：以八个问题为纵轴，画一张「已会能力 / 新增能力」地图；从主链路里选一段，写出用什么现象证明它跑通了。这份作业直接作为第 02 节的输入。

## 决定与约定
- 知识库现有文件：`00-索引与待确认清单.md`、`01-课程大纲-讨论稿.md`（课程主干）、`03-宣发物料-新版整理稿.md`（现行宣发稿）、`04-开写前确认清单.md`，以及子文件夹 `讲义/`。
- 讲义按节号放在 `讲义/`，例如 `讲义/01-第01节大纲-讨论稿.md`、`讲义/01-第01节讲义-文字稿.md`。顶层的 05 号留给「大纲修订稿」。
- `02-宣发物料-旧版.md` 已删除，可以从 git 历史找回。以后写稿不再以旧版为依据。旧版里的旧口径已记在 00 的不一致清单里。
- 各节讲义里的待确认项如果和 `04-开写前确认清单` 重复，只写编号（如 D8、C1），不重复展开。
- 各类稿子用的 skill：
  - 用 ai-course-writing：大纲、修订稿、阶段验收、评分表、作业设计、宣发。
  - 用 ai-course-writing-original：单节讲义正文和视频讲稿，偏口语，像讲课。
  - 配图走设计师 Agent 的画图规范，或者由我按规范给出 Mermaid 源码。
- 文字资料每节控制在 4000～7000 字。「我」只用来表达判断，不编造讲师经历。
- 设计原则：任务状态、权限、费用这类确定的事实由控制面持有，不放在 Router 的模型 Session 里。
- 学员已有的 Web、数据库、调度、部署能力落在入口和控制面，新要学的集中在 Agent 那一侧。
- 文件改动不主动提交 git；什么时候提交由用户决定。
- 稿子暂时写作「SuperAgent」。
