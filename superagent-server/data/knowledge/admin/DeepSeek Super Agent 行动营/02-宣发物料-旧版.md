探索 Coding Agent 下一站：构建企业级 Super Agent

会用 Codex、Claude Code 写代码，与能设计出一个供企业员工持续使用的 Agent 系统，是两种不同的工程能力。

前者关注单个任务怎样做完；后者还要回答任务从哪里来、该由谁执行、执行时能访问什么、并发任务如何隔离、失败后怎样恢复、花费多少成本、谁来验收，以及工作结果如何留在企业。

DeepSeek 的 Super-agent 架构，给出了一条 "迈向更自主的 Agent 系统" 的重要路线——Router 维护跨信道的连续交互，Worker 隔离并行执行具体任务；事件驱动让 Agent 主动工作；异步调用、状态与环境分离、Watchdog 支撑长期运行。

本期行动营，我们将以这些架构设计方法为起点，完成属于自己的企业级 Super Agent，建立企业 AI 工作系统的产品判断和工程主干，掌握 AI 工程师的岗位模型。

4 周构建 Super Agent 产品原型与工程主干

你将获得：

1. 系统判断：看懂持续运行的 Agent 系统，分清入口、控制面、Router、Worker 各自负责什么，并为第一版写出产品定义与验收标准。
2. 执行能力：接入一种真实 Coding Agent，管理 Session、流式事件、取消、用量和工作区，让 Worker 可以独立执行一项任务。
3. 平台能力：用 Spring Boot、MySQL 构建 Chat、Task 和 Automation，保存执行过程、交付物与人工确认，让任务离开网页也能继续。
4. 企业场景与作品：接入一个真实事件入口，跑通受权限约束的知识访问；用研发任务和内容生产两条路径验收系统，整理产品架构、设计取舍与演示作品。

课程目录
第一周：产品与架构
目标：确定产品要服务谁、完成哪项工作，画出可指导实现的系统边界。

01｜透视 Super Agent ：一个持续工作的 Agent 靠哪几层工程能力？
02｜第一版产品边界：做 Super Agent 之前，先锁定一个业务场景
03｜双视角设计 AI 工作台：员工与管理员并行操作，产品要做哪些页面？
04｜画清 Super Agent 架构：控制面、Router 与 Worker

第二周：Worker 运行层
目标：让一种真实 Coding Agent 在受控工作区独立执行，留下可追踪的状态与用量。

05｜两种 Agent Runtime：自建 Loop 与原生 Coding Agent
06｜运行时怎样持续工作：状态、异步与 Watchdog
07｜谁来做这项工作：Agent 选择、模型路由与用量归因
08｜把 Worker 放进受控环境：工作区、授权与人工接管

第三周：控制面与工作入口
目标：把员工的对话变成可持久、可恢复、可验收的工作任务。

09｜搭起控制面：Spring 服务、存储、日志与部署
10｜实现 Chat：接收目标，同时保持对话可继续
11｜实现 Task：把目标、执行与交付分开保存
12｜实现 Automation：让系统在约定时间主动创建工作

第四周：事件驱动与企业场景
目标：从员工主动提问扩展到事件触发，用研发与内容两类任务，验收系统的复用能力。

13｜接入第一个外部信道：IM、Webhook 与事件身份
14｜事件怎样变成任务：聚合、过滤、归属与低打扰
15｜Super Agent MCP：让 Agent 获取企业能力，也让外部 Agent 使用平台
16｜验收 Super Agent：让项目变成 AI 工程师的面试作品与能力证据

Q：课程视频的有效期是多久？
本期课程视频永久有效，其中包含 "学期" 和 "观看期"。
学期：指我们为大家提供学习服务的时间，也就是开营起到结业的时间。在此期间，学员可以观看课程视频，并享受相应的学习服务，比如讲师答疑、班主任督学等等。
