1起点

AI 已经能干活了，公司却还没有一个让 AI 干活的地方。
  • 模型能干活了。它们能写代码、写文档、做分析、读资料，能连续几十分钟独立推进一件事。这已经不是「回答问题」，而是「完成工作」。
  • Agent 成熟了。Claude Code、Codex 这一类官方 Agent，把模型变成了真正能在电脑上执行、读写文件、调用工具的工作者，而且每周都在变强。
  • 员工已经在用了。几乎每家公司都有人自己买 token、自己装 Agent，在自己的电脑上让 AI 干活。效率实实在在地提升了。

可是这些使用全部发生在个人的电脑上：账号是个人的，花费是个人的，做出来的东西留在个人的硬盘里，用了什么数据、做了什么操作，公司一概不知。每个人都在单打独斗，公司作为一个整体，并没有因此变得更会做事。

这就是 SuperAgent 的起点：AI 的使用正在从个人走向公司，公司需要一个系统，把这些分散的使用收拢起来。

花得乱各自订阅、重复付费，什么事都用最贵的模型统一管理，按任务选模型，每一分钱都追得到

这些问题有同一个根源：工作发生在个人的地方。只要还是这样，模型再强，这些问题也不会自己消失。

3六个核心判断

01

分散的 AI 使用，一定会被公司收拢

每一种进入公司的技术都走过这条路：先是个人自发地用，规模大了，公司就需要统一管理。AI 也一样。员工自己买 token、装 Agent 的阶段会过去，公司会需要一个系统来统一管理、统一运行、统一积累。这个系统长期的核心价值有三个：管控、积累、成本。

02

智能交给模型和官方 Agent，我们不重造

直接调用模型 API、自己搭运行循环、自己写工具调用，一定跟不上官方 Agent：模型和它自家的 Agent 是一起调教、一起迭代的，几乎每周都在进步。所以 SuperAgent 不做执行框架、不做推理循环，也不和模型去抢「怎么把一件事做好」。我们走 runtime + CLI 的路线：直接驱动官方的 Agent，让它们去干活。

这样选，模型和 Agent 的每一次进步，都会直接变成 SuperAgent 的进步。模型越强，SuperAgent 越强。

03

价值在组织层

一个 Agent 再强，也只是在一个人的一次会话里把一件事做好。公司需要的是另一层东西：成果归谁、谁能看、怎么交接、谁来做、花了多少、做了什么、和哪些系统打通、出了问题谁负责。这些都是跨人、跨时间、跨系统的事，只能由一个公司级的系统来承担。

SuperAgent 要做的，就是这一层：让公司用好 AI，降本提效。

04

对模型厂商保持中立

SuperAgent 不绑定任何一家模型厂商。各家模型，包括客户自己的模型网关和私有部署的模型，都能接进来。不同的任务用不同的模型：难的交给最强的，日常的交给又好又便宜的，以此把成本降下来。模型格局变化很快，中立让公司始终能用上当下最合适的那一个，而公司攒下的资产不属于任何一家模型。

05

让 Agent 守规矩，公司才敢用

Agent 能执行任意命令、读写任意文件，这是它强大的地方，也是公司不敢放手的原因。SuperAgent 要让它守规矩：每个 Agent 都在隔离的环境里运行，只能碰它该碰的东西；凭证由公司统一保管；它做的每件事都有记录；关键决定回到人手里。能被管住，才能被放手。

06

任务越来越复杂，越需要一个系统来跑

交给 AI 的任务会越来越长、越来越复杂：从几分钟到几小时，从一个人到一个团队，从一次性到每天自动运行。公司会越来越需要一个系统来分配、调度、追踪、运行这些任务，保证它们持续、可靠、低成本地跑完：该找谁做、放在哪里跑、卡住了怎么办、失败了怎么重来、结果交给谁。

4为谁而做

SuperAgent 为公司而做，用户是公司里的每一个人。

谁关心什么SuperAgent 给他什么
员工好用，省事，能把活干完入职就有能干活的 AI 团队，说一句要什么，有人拆、有人做、有人跟进
团队负责人大家能一起推进，人员变动不断档围绕同一个 Agent 协作，好方法变成团队的技能，交接时有一个熟悉情况的 Agent
公司负责人效率、成本、风险，以及公司攒下了什么全公司 AI 使用的审计、分析、管控和治理；成本由系统优化；资产越积越多
IT 与安全部署、权限、数据、合规部署一次全员可用；统一的 Key 和授权；Agent 隔离运行、有据可查；可以私有化部署

最先需要它的，是这样的公司：知识型工作多、员工已经在自发地用 AI、希望把它统一管起来、用到更多人身上。研发、产品、运营、咨询、内容这些团队，是 AI 最先能大规模干活的地方。

5核心竞争力

  1. 1
    工作自动沉淀为公司资产所有人在一个系统里和 AI 干活，文件、Agent 的记忆、技能自动留在公司。积累只能在日常工作里长出来，每家公司的积累都是它自己独有的，越用越值钱。
  2. 2
    协作与交接多人和同一个 Agent 推进同一件事；每个人有一个 SuperAgent 负责拆解和分发；人离开时，Agent 和上下文交给下一个人继续。
  3. 3
    方法复用个人和公司两级技能，把高手的做法变成全员的默认能力。
  4. 4
    中立与成本不绑定模型厂商，按任务选最划算的模型；统一 Key、统一计量，每一分花费都能追到人、任务和模型。
  5. 5
    审计、管控与治理Agent 隔离运行、守规矩；做过的事查得到；关键决定有人拍板；全公司的使用情况看得清。

5.1 支撑它们的三个选择

站在最强的 Agent 上走 runtime + CLI 路线，直接驱动官方 Agent。Agent 的智能来自整个行业最好的那一批，并且自动跟着变强。
做在组织层只做跨人、跨时间、跨系统的事。这一层和模型的进步是互相成全的：模型越能干，越需要被管起来、攒下来、调度好。
一套系统，两种形态同一套代码，既能作为 SaaS 服务很多家公司，也能私有化部署在一家公司里；接得上客户自己的模型和内部系统。

6要做成的样子

企业的 AI 协作工作系统
全员与 AI 在一个系统里协作，工作沉淀为公司资产。
  • 员工每天在这里干活。打开它，看到的是需要自己处理的事；说一句要什么，有一个 AI 团队去做。
  • 每个人都有一个 AI 团队。SuperAgent 是负责人，下面是各有专长的 Agent，人负责提要求和做决定。
  • 它是公司所有 AI 工作的总入口和总账。谁在用、做了什么、花了多少、攒下了什么，都在这里。
  • 它连着公司的一切。飞书、钉钉、代码仓库、文档、内部系统，Agent 用员工自己的身份去读写。
  • 它让任务跑得稳。大大小小的任务被分配、调度、追踪，持续、可靠、低成本地完成。

7愿景

让公司作为一个整体，越来越会做事。
自动化 · 智能化 · 全天候。同样的人，做更多的事；同样的事，需要更少的人。

今天，SuperAgent 让每个人和 AI 一起把事做完。随着模型变强、软件成熟、公司的业务知识越积越多，需要人介入的地方会越来越少：先是 AI 做完、人确认关键节点，再是流程自动地跑、人只看结果，最后系统全天候地运转，人只负责方向、判断和真正重要的决定。

每一步都建立在前一步攒下的东西上。今天沉淀下来的每一份文件、每一条记忆、每一个技能，都是明天自动化的燃料。这条路没有终点，只有一步一步地往前走。

8判断成立的前提

前提它支撑了什么
模型会持续变强、变便宜AI 能接手的工作越来越多，自动化的路能走下去；按任务选模型的省钱空间一直存在。
官方 Agent 会持续进步，并以 CLI 等形式可以被驱动runtime + CLI 路线成立：我们不重造智能，而是站在最强的 Agent 上。
不会只有一家模型一直领先中立有价值：不同任务、不同时期，最合适的模型不同。
公司会把 AI 当作需要管理的生产力收拢是必然：管控、积累、成本成为公司的真实需求。
业务知识能在日常工作中积累下来，并且越积越有用沉淀资产成为最核心的价值，也是自动化最重要的燃料。

模型负责变强，Agent 负责把事做好，SuperAgent 负责让公司用好它们：管得住、攒得下、花得省、跑得稳。这是 SuperAgent 存在的理由，也是它能做成的理由。
