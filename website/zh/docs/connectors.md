# 连接与消息

连接把公司和一个外部系统接起来。**管理员添加,需要以员工本人身份使用的由员工自己授权。** 授权到位后 Agent 才能用,而且总是以它为之工作的那个人的身份使用。

## 「连接」页面上有什么

| 连接 | 用途 | 授权 |
| --- | --- | --- |
| **SuperAgent**(内置) | SuperAgent 自带工具:任务、文件、Skills、自动化、团队 | 无需授权。启动时自动识别并自检,接入每一次运行,不可修改 |
| **飞书** | 消息流向每个人的 SuperAgent | 每位员工关联自己的飞书账号 |
| **GitHub** | 仓库、Issue、Pull Request | 每位员工用自己的 GitHub 账号授权 |
| **Gitee** | Gitee 上的仓库 | 每位员工用自己的 Gitee 账号授权,Token 自动续期 |
| **公司自己的 MCP 服务** | MCP 服务提供的任何工具 | 无需授权、公司统一 Token,或员工各自的 Token |

每一行都显示你自己的授权状态:授权、填 Token、取消授权。管理员还能看到有多少人已授权。

## 添加自己的 MCP 服务

管理员可以在「连接」页添加任何 MCP 服务:

- **传输方式**:服务器上运行的命令(stdio),或一个 URL(HTTP / SSE)。stdio 服务只有 Claude Code 能用,其他 CLI 使用 HTTP / SSE 服务。
- **授权方式**:无需授权;**公司统一 Token**;或**员工各自的 Token**,让 Agent 以这个人的身份操作。
- Token 加密保存,保存后不再显示。

## 公司应用

GitHub、Gitee 和飞书需要公司在对方平台上的应用(OAuth 应用、飞书应用)。管理员在[系统设置 → 连接配置](./admin#连接配置)里配一次;配好之前,这些连接显示「未配置」,员工无法授权。

## 飞书

全公司共用一个飞书应用。

- **关联员工**:按手机号自动匹配员工的飞书账号。匹配不上的员工在「连接」页拿一个绑定码,私聊发给机器人。
- **消息给谁**:私聊机器人的消息,进发送者本人的 SuperAgent;群消息分给群里每一位已关联的成员,各自分拣。
- **之后**:你的 [SuperAgent](./superagent#外部消息) 分拣并处理;紧急的事会通过飞书私聊提醒你。
- 机器人只能看到发给它的消息,以及它所在群里的消息,看不到员工之间的私聊。
