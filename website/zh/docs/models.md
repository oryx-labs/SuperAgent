# 模型与成本

员工入职第一天就能用 AI,用的是公司的 Key。不需要任何人自费订阅,花了多少公司都看得见。

## 模型 CLI

管理员在「模型」页管理干活的编码 Agent CLI:

<Shot name="models" alt="编码 CLI:安装、升级以及可用的模型" />

- **一键安装和升级**,使用各家官方的安装包。服务器没有 Node.js 时,会为 SuperAgent 单独装一个。
- **模型列表**:从每个 CLI 和它的 Key 拉取,并用真实请求验证,列出来的就是确实能用的。
- **已支持**:Claude Code、OpenAI Codex、DeepSeek Harness、Kimi Code、Qwen Code,以及通过 Claude Code 运行的 GLM。CodeBuddy、MiniMax Code、Gemini CLI 可以安装、配置 Key,执行工作稍后支持。

## API Key

每个 CLI 有一个按优先级排列的地址和 Key 池:

<Shot name="model-keys" alt="一个 CLI 的 Key 池:优先级、状态和失败原因" />

- **多个 Key、多个地址**:官方 API、中转或网关,各配各的 Key。
- **失败自动切换**:运行时用排在最前面且正常的那个。如果调用失败的原因是换个 Key 能解决的(Key 无效、额度用完、服务不可用),就切到下一个并重试一次;原来那个恢复后再切回去。
- **健康检查带原因**:每个 Key 都用真实请求检查。失败时说明原因:Key 无效、没有权限、余额不足、请求过于频繁、地址不对、连不上。
- **默认走官方地址**:没填地址的 Key 发往官方地址,页面上会显示出来。
- **服务器上已有的 Key**:启动时自动发现并导入。
- Key 加密保存,页面上只显示打码后的形式。

## 模型怎么选

SuperAgent 不绑定任何一家模型厂商。公司配了 Key 的模型都能用,每项工作交给最合适的那一个。

- **对话**用公司的**默认模型**(管理 → 系统设置 → 基本设置)。默认模型出了模型层面的问题(Key 失效、额度用完、地址不通),对话会无感地换到备用列表里的下一个模型,默认模型恢复后再换回来;切换时会通知管理员。
- **任务自己选模型**。任务开始前,由默认模型判断难度,选出**够用的最便宜的模型**;做不成就升一级。任务的**模型选择**标签页会显示选了哪个、为什么。
- **后台小活**(给文件打标签、整理记忆)用能跑的最便宜的模型。
- **模型价格**(管理 → 模型 → 价格)列出能运行的模型和官方价。管理员可以填实际支付的价格(比如走中转时),也可以让某个模型不用于任务。花费估算和选模型都按这里的价格。

## 看清花费

- **每个任务**都记录花费。
- **分析**页(管理员)显示:用户数和活跃用户、任务量和成功率、Agent 数、定时任务、总花费、每天的任务量,以及**按模型的花费**。
