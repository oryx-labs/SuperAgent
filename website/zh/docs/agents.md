# Agent 与协作

Agent 是公司留得住的同事。它的设定、记忆和产出的文件都属于公司,而不是属于碰巧创建它的那个人。

## 创建 Agent

- **性格** —— 从 24 种预置性格里选,或者自己写。它决定 Agent 怎么做事、怎么说话。
- **模型** —— 指定一个模型;开启[模型档位](./models#模型档位-预览)后也可以选档位(快速 / 标准 / 强)。都不选就用系统默认。
- **Skills** —— 挂上 Agent 要遵循的 [Skills](./files#skills),你能看到的都可以挂:自己的和公司的。
- **头像和名字** —— 方便大家区分。

## 对话

- 回复边写边显示;一个 Agent 可以有多个会话。
- **什么都能发**:文件、图片、链接。它们会存进[文件](./files)并关联到这个 Agent,工作和资料放在一起。
- **交付物就是文件**:你要文档、报告、代码、图片、视频时,Agent 会把它交付成文件,在「文件」里能找到,而不只是对话里的一段文字。
- 在对话里,Agent 还能创建[任务](./tasks)和[自动化](./tasks#自动化),并使用公司的[连接](./connectors)。

## 长期记忆

- 每个 Agent 有自己的记忆,记下它对这份工作学到的东西,在之后的对话里用上。
- 成员可以查看;所有者可以编辑,也可以让 Agent 把一段对话提炼进记忆。
- 只记值得留下的东西,宁缺毋滥。

## 和同事协作

- **协作 Agent:一个 Agent,多个人。** 把同事加为成员,一起推进同一件事。每个成员的消息都会推动工作,所有人实时看到对话。
- **在对话里邀请。** 让 Agent(或你的 SuperAgent)拉人进来:它在通讯录里找到这个人并发起邀请,所有者在对话里点一下确认。移除成员立即生效。
- **只有所有者能改设定**(性格、模型、Skills、记忆),成员按现有设定使用。

## 运行日志

每个 Agent 都有运行日志:它的会话、每一轮、记忆变更,以及 SuperAgent 做了什么。所有者可以查看,保留 30 天。

## 待办

待办是每个人的首页,汇总来自任务、SuperAgent 和消息的待处理事项:

<Shot name="todo" alt="待办首页:需要你处理的事,以及 Agent 做完的事" />

| 标签 | 内容 |
| --- | --- |
| 全部 | 现在需要你处理的所有事 |
| 待确认 | Agent 在等你拍板的事,比如暂停等决定的任务、等批准的计划 |
| 待执行 | 需要你亲自做的事,比如从消息里提取出来的 |
| 已完成 | Agent 做完的工作 |
| 通知 | 值得知道的事 |
| 已忽略 | 你搁置的事,随时可以恢复 |

顶部的统计显示现在有多少待处理,以及 Agent 今天、本周、本月和累计完成了多少。
