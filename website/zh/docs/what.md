# SuperAgent 是什么

**SuperAgent 是公司的 AI 工作系统,不是个人助手。** 公司里所有人都在一个系统里完成工作,这些工作会自动沉淀为公司的资产,不会因为人员变动而丢失。

## 不是个人助手

现在大多数 AI agent 都是个人助手:帮一个人提效,工作留在这个人的账号里,人走了就带走了。每个员工各自订阅,token 浪费没人管,公司也看不见发生了什么。

SuperAgent 从**公司和公司员工**的角度出发。企业对 AI 是刚需,要的是能真正用起来的东西:好用、省钱、什么工作都能做。所以 SuperAgent 是公司部署一次、全员使用的系统:

| | 个人 AI 助手 | SuperAgent |
| --- | --- | --- |
| 服务谁 | 一个人 | 整个公司和它的员工 |
| 工作去哪了 | 个人账号里,人走即丢 | 自动沉淀为公司资产 |
| 怎么协作 | 各干各的 | 共享 Agent,离职可交接 |
| 成本 | 每人自费订阅,token 浪费 | 入职即用,按量计费,按难度选模型 |
| 管控 | 公司看不见 | 公司可控、可审计、接入审批 |

## 它做什么(按优先级)

1. **工作即资产。** 所有人在一个系统里工作。Agent 的产出和员工发来的资料存进「文件」,每个 Agent 积累自己的长期记忆。
2. **协作与交接。** 多人可以在同一个 Agent 上协作;有人离职,Agent 和上下文交接给下一个人。
3. **方法复用。** 个人和公司两级 Skills;Agent 的设定、记忆和文件都属于公司。
4. **成本与模型。** 不用自费订阅,按量计费,模型无关,按任务难度路由模型。
5. **审计与安全。** 自带审计和安全体系,接入办公工具和审批。
