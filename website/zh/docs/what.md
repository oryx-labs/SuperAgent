# SuperAgent 是什么

**SuperAgent 是企业的 AI 协作工作系统,不是个人助手。** 公司里所有人都和 AI 在一个系统里干活,这些工作沉淀为公司的资产,不会因为人员变动而丢失。

## 起点

AI 已经能干活了。模型能写代码、写文档、做分析,Claude Code、Codex 这样的官方 Agent 能独立把一件事推进完。员工也已经在用:自己买 token、在自己的电脑上装 Agent,效率实实在在地提升了。

可是这些使用都发生在个人的地方:账号是个人的,花费是个人的,做出来的东西也留在个人那里。公司看不见做了什么,没法在上面继续,人一走就没了。每个人都变快了,公司作为一个整体却没有因此变得更会做事。SuperAgent 要做的,就是把这些分散的使用收拢到公司的一个系统里。

| 今天 | 有了 SuperAgent |
| --- | --- |
| 会折腾的人用得好,其他人用不上 | 入职就有 AI 用,不用订阅、不用配置 |
| 成果留在个人账号里,人一走就没了 | 工作在公司的系统里发生,沉淀为公司资产 |
| 同一件事没法接着别人做 | 多人和同一个 Agent 协作,Agent 和上下文留在公司 |
| 好方法只在发现它的人手里 | 方法沉淀成 Skills,先个人、再全公司 |
| 各自付费,什么事都用最贵的模型 | 公司统一的 Key,每个任务自动选够用的最便宜的模型 |
| 公司看不见、管不住 AI 做了什么 | 用量、运行日志、分析;关键处由人拍板 |
| 个人的 Agent 接不上公司的系统 | 飞书、钉钉、Git、文档统一打通,员工用自己的身份授权 |

## 整体架构

SuperAgent 不重造 Agent,而是直接驱动官方的 Agent CLI,自己专注公司层面的事:谁来做、在哪里跑、用哪个模型、花了多少、成果归到哪里。**控制面**负责界面、业务逻辑、数据和密钥;Agent 在**沙箱**里干活,每个员工一个。

![SuperAgent 分层架构](/diagrams/architecture-layers-zh.jpg)

这是目标架构。当前版本仍是控制面和 Agent CLI 跑在同一台服务器上;细节和还在建设的部分见[技术架构](./architecture)。

## 它做什么(按优先级)

1. **工作即资产。** 所有人在一个系统里工作。Agent 的产出和员工发来的资料自动归档到「文件」,每个 Agent 积累自己的长期记忆。
2. **协作。** 多人在同一个 Agent 上协作;你的 SuperAgent 拆解工作,交给 Agent 和任务去做。
3. **方法复用。** 个人和公司两级 Skills;Agent 的设定、记忆和文件都属于公司。
4. **模型中立、节省成本。** 不用自费订阅;公司的 Key 统一管理、失败自动切换;每个任务自动选够用的最便宜的模型;按人、按任务、按模型看花费。
5. **看得见、用得安全。** 计划和关键决策由人拍板;分析、权限、运行日志、密钥加密。
