# 任务与自动化

## 任务

任务是 Agent 独立完成的一件事:从需求跑到结果,你可以同时做别的。

<Shot name="tasks" alt="任务列表:状态、模型、来源和花费" />

- **怎么发起**:在任务页、在对话里、由你的 SuperAgent,或者由自动化发起。
- **后台运行**:在受管的会话里执行。看门狗会发现卡住的运行,服务重启后任务会接着跑。
- **该问就问**:需要你拍板时任务会暂停等待,你在任务里回答后它继续。等你的任务会出现在[待办](./agents#待办)里。
- **随时指挥**:给任务发消息就能调整方向。
- **编码流程**:工程类任务按固定阶段走:需求、开发、验收。
- **结果**:交付物进[文件](./files),任务详情里以「产出文件」列出;事件流逐步记录做了什么。
- **花费**:每个任务都记录花了多少钱。

任务页顶部有统计(全部、进行中、等你处理、今天完成、失败、本月花费),列表里能看到每个任务的 Agent、模型、来源、时间、花费和状态。

## 自动化

自动化让重复性的工作按时跑起来,不用有人记着去启动。

<Shot name="automation" alt="自动化:定时、Cron、一次性和 API 触发" />

| 触发方式 | 用途 |
| --- | --- |
| **定时** | 每天、每周、每小时…… |
| **Cron** | cron 表达式能描述的任何时间 |
| **一次性** | 在指定时间跑一次 |
| **API** | 别的系统带着这个自动化自己的 Token 调用一个地址时触发 |

- 在任务页创建,或者**直接在对话里说**(「每周一 9 点,总结一下……」)。
- 保存前可以预览接下来的运行时间;可以立即运行、暂停和恢复。
- 每次运行都会发起一个任务,所以结果、花费和历史和其他任务一样。
