# 任务与自动化

## 任务

任务是 Agent 独立完成的一件事:从需求跑到结果,你可以同时做别的。

<Shot name="tasks" alt="任务列表:状态、模型、来源和花费" />

- **怎么发起**:在任务页、在对话里、由你的 SuperAgent,或者由自动化发起。
- **后台运行**:在受管的会话里执行。看门狗会发现卡住的运行,服务重启后任务会接着跑。
- **该问就问**:需要你拍板时任务会暂停等待,你在任务里回答后它继续。等你的任务会出现在[待办](./agents#待办)里。
- **随时指挥**:给任务发消息就能调整方向。
- **编码流程**:工程类任务按固定阶段走:需求、开发、验收。
- **结果**:交付物进[文件](./files),任务详情里以「产出文件」列出;事件流逐步记录做了什么。
- **花费**:每个任务都记录花了多少钱。

任务页顶部有统计(全部、进行中、等你处理、今天完成、失败、本月花费),列表里能看到每个任务的 Agent、模型、来源、时间、花费和状态。

### 复杂任务

大的工作可以发起**复杂任务**:它先做计划,把工作拆成子任务并行执行,最后汇总结果。

- **拆分、并行**:默认最多 10 个子任务、同时运行 5 个;管理员可以在「系统设置 → 基本设置」里调整上限。
- **等子任务完成**:子任务运行期间,任务显示「子任务执行中」;全部完成后自动汇总并结束。
- **每部分用合适的模型**:计划和汇总用默认模型;每个子任务用够用的最便宜模型。
- **失败会补救**:子任务失败时先换更强的模型重试;仍然失败,汇总里会写明,任务可以把这部分再派一次。最多汇总三轮,最后一轮必须给出结论,并说明缺了什么。
- **全程不打断你**:复杂任务和它的子任务都不会停下来等你确认。
- **列表里只占一行**:任务列表只显示这个复杂任务;详情页有「子任务」标签,花费包含所有子任务。
- 在对话里,Agent 也可以替你发起复杂任务。

### 接着做

想在一个已完成的任务基础上继续,点它详情页上的**「接着做」**,或者在对话里让 Agent 发起。新任务会带上上一个任务的结论、这条链上最近最多 5 个任务的摘要,以及上一个任务的工作目录。详情页会显示「接续自」哪个任务,以及它的「后续任务」。

### 标签和筛选

- 任务完成后会自动打上 **2~4 个主题标签**,优先复用你已有的标签;你可以在详情页修改。子任务不打标签。
- 任务列表可以按**标签、Agent、来源**筛选,并显示筛选出的数量和花费;每个筛选项旁边也标着它自己的数量和花费。

## 自动化

自动化让重复性的工作按时跑起来,不用有人记着去启动。

<Shot name="automation" alt="自动化:定时、Cron、一次性和 API 触发" />

| 触发方式 | 用途 |
| --- | --- |
| **定时** | 每天、每周、每小时…… |
| **Cron** | cron 表达式能描述的任何时间 |
| **一次性** | 在指定时间跑一次 |
| **API** | 别的系统带着这个自动化自己的 Token 调用一个地址时触发 |

- 在任务页创建,或者**直接在对话里说**(「每周一 9 点,总结一下……」)。
- 保存前可以预览接下来的运行时间;可以立即运行、暂停和恢复。
- 每次运行都会发起一个任务,所以结果、花费和历史和其他任务一样。
