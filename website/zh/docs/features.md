# 功能说明

SuperAgent 从公司的角度设计:服务的是公司和公司的员工,而不是一个人和他的助手。下面的能力按优先级排列,标注「即将推出」的部分正在建设。

## 1. 工作沉淀为公司资产

公司所有人都在同一个系统里工作,工作留在公司,不会跟着人走。

- **文件。** Agent 产出的所有东西,以及员工发给它的文件和链接,都存进「文件」,可以追溯到产生它的任务。
- **Agent 记忆。** 每个 Agent 有自己的长期记忆,越用越懂这份工作。成员可以查看,Agent 的所有者可以编辑。
- **不随人走。** 有人换岗时,Agent 连同它的记忆和文件一起留下。

## 2. 协作与交接

员工之间的协作在一个 AI 系统里完成。

- **共享 Agent。** 同一件事,几个人可以在同一个 Agent 上协作,让它把任务完成。每个成员的消息都会推动工作往前走。
- **离职交接。** 有人离职时,Agent 和上下文可以交接给下一个人,在前人的基础上继续。*(即将推出)*

## 3. 方法复用

好的做法,变成全公司都能用的规范。

| Skills | 谁能用 | 谁能改 |
| --- | --- | --- |
| **公司** | 公司所有人 | 管理员 |
| **个人** | 仅员工本人 | 员工本人 |

Skills 是可复用的指令集,Agent 和任务按需加载。Agent 也是团队资产:它的设定、记忆和文件都属于公司,新人直接接手,不用从零开始。

## 4. 成本、模型与治理

员工入职就有 AI 可用,不需要自费订阅。

- **按量计费。** 公司为实际用量付费,避免每个员工各自浪费 token。
- **花费可见。** 按任务、按模型、按月统计花费。
- **模型无关。** 模型供应商集中接入和切换,有系统级默认配置;Claude Code、Codex 等编码 Agent 也在同一套管控下运行。
- **按难度路由。** 根据任务难度自动选择合适的模型,帮公司省钱。*(即将推出)*

## 5. 审计与安全

让 AI 在公司里用得安全、看得见。

- **人工确认。** 关键决策要等人确认后才继续。
- **身份与权限。** 用户、团队和访问规则由公司统一管理。
- **运行日志。** 每个 Agent 的会话、每一轮、记忆变更和行为都有记录。
- **办公工具。** 通过飞书等连接器,工作从员工常用的工具进来。
- **审批。** 对接企业审批流程。*(即将推出)*

## 还包括

- **每人一个 SuperAgent。** 每位员工的 SuperAgent 把工作收进收件箱,先计划后执行,组建小团队派活,并回报结果。
- **任务执行。** 任务在受管会话中从需求跑到结果,包括专门的编码流程。
- **自动化。** 定时、一次性和 API 触发的自动化,可以直接在对话中创建。

## 一句话

**公司可控、节省成本、自动沉淀资产、好用。**
