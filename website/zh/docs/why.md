# 为什么选 SuperAgent

对公司来说,AI 已经是刚需。需要的是**真正用得起来**的 AI:好用、省钱、什么工作都能做。给每个员工发一个个人助手,做不到这一点。

## 个人助手的问题

- **工作跟着人走。** 对话、上下文和方法都在个人账号里。有人转岗或离职,公司只能从头再来。
- **没法在别人的基础上继续。** 同事不能在同一件事上用同一个 AI 协作,接手的人也接不上前任的工作。
- **什么都沉淀不下来。** 一个人摸索出来的东西,变不成团队或公司能用的东西。
- **成本分散又浪费。** 员工自己掏钱订阅(或者干脆用不上),所有事情都用最贵的模型。
- **公司看不见。** 没有审计、没有安全边界,也接不上审批。

## SuperAgent 的做法

- **全员一个系统。** 所有工作都在公司的系统里发生,自然成为公司的资产:文件,以及会记事的 Agent。
- **协作。** 多人共享 Agent 推进同一件事;每个人的 SuperAgent 带一个小团队干活。
- **方法复用。** 个人和公司两级 Skills,以及留在公司的 Agent。
- **入职即用公司的 Key。** 不用个人订阅;Key 统一管理、失败自动切换,按任务、按模型看花费。
- **看得见、用得安全。** 计划和关键决策由人拍板;权限、运行日志、密钥加密;接入飞书。

## 结果

**公司可控、节省成本、自动沉淀资产、好用。**
