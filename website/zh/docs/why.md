# 为什么选 SuperAgent

**AI 已经能干活了,公司却还没有一个让 AI 干活的地方。** 员工在各自用 AI:自己的 token、自己的 Agent、自己的电脑。公司需要一个系统把这些使用收拢起来,让它管得住、攒得下、花得值。

## 我们的判断

1. **分散的 AI 使用,一定会被公司收拢。** 每一种进入公司的技术都走过这条路:先是个人自发地用,规模大了,公司就要统一管理。AI 也一样。承担这件事的系统,长期的核心价值是**管控、积累、成本**。
2. **智能交给模型和官方 Agent,我们不重造。** 直接调模型 API、自己搭运行循环,一定跟不上官方 Agent:它们和自家模型一起调教,每周都在进步。所以 SuperAgent 不重造执行框架,而是直接驱动官方的 Agent CLI。模型和 Agent 的每一次进步,都会直接变成 SuperAgent 的进步。
3. **价值在组织层。** 一个 Agent 再强,也只是在一个人的一次会话里把一件事做好。公司需要的是另一层东西:成果归谁、谁能看、怎么交接、谁来做、花了多少、和哪些系统打通。这些都跨人、跨时间、跨系统,只能由公司级的系统承担。SuperAgent 要做的,是**帮公司用好 AI,降本提效**。
4. **对模型厂商保持中立。** 各家模型都能接进来,包括公司自己的模型网关和私有部署的模型。不同的任务用不同的模型:难的交给最强的,日常的交给又好又便宜的。模型格局变化很快,中立让公司始终能用上当下最合适的那一个,而公司攒下的东西属于公司,不属于任何一家模型。
5. **让 Agent 守规矩,公司才敢用。** Agent 能执行任意命令、读写任意文件,这是它强大的地方,也是公司不敢放手的原因。SuperAgent 让每个 Agent 在隔离的环境里运行,凭证由公司统一保管,做的每件事都有记录,关键决定回到人手里。**能被管住,才能被放手。**
6. **任务越复杂,越需要一个系统来跑。** 交给 AI 的任务从几分钟变成几小时,从一个人变成一个团队,从一次性变成每天自动运行。公司需要一个系统来**分配、调度、追踪、运行**它们,保证持续、可靠、低成本地跑完。

## 为谁而做

SuperAgent 为**公司**而做,用户是公司里的每一个人。

| 谁 | 关心什么 | SuperAgent 给他什么 |
| --- | --- | --- |
| 员工 | 好用,省事,能把活干完 | 入职就有能干活的 AI 团队,说一句要什么,有人拆、有人做、有人跟进 |
| 团队负责人 | 大家能一起推进,人员变动不断档 | 围绕同一个 Agent 协作,好方法变成团队的 Skills,交接时有一个熟悉情况的 Agent |
| 公司负责人 | 效率、成本、风险,以及公司攒下了什么 | 全公司 AI 使用的审计、分析和管控;成本由系统优化;资产越积越多 |
| IT 与安全 | 部署、权限、数据、合规 | 部署一次全员可用;统一的 Key 和授权;Agent 隔离运行、有据可查;可以私有化部署 |

最先需要它的,是知识型工作多、员工已经在自发用 AI、希望把它统一管起来并用到更多人身上的公司。

## 要走向哪里

**自动化 · 智能化 · 全天候。** 同样的人,做更多的事;同样的事,需要更少的人。

今天,SuperAgent 帮每个人和 AI 一起把事做完。随着模型变强、软件成熟、公司的业务知识越积越多,需要人介入的地方会越来越少:

1. **人带着 AI 干。** 每一步人都在。
2. **AI 做完,人确认关键节点。** 常见的事 AI 独立做完,人在交付前和需要拍板时介入。
3. **流程自动跑,人看结果。** 重复的工作变成自动化,人只处理例外。
4. **全天候运转,人定方向。** 系统持续地接收、处理、交付;人负责目标和真正重要的决定。

![随着使用时间增加,Agent 自己完成的工作越来越多,需要人介入的越来越少,每件事的成本越来越低](/diagrams/product-automation-trend-zh.jpg)

今天攒下的每一份文件、每一条记忆、每一个 Skill,都是明天自动化的燃料。目标始终落在工作本身:SuperAgent 是公司干活的地方,不是搭建 AI 的平台。
