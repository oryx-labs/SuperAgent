# 文件与 Skills

## 文件

「文件」是工作成果存放的地方,让成果留在公司,而不是散落在聊天记录里。

<Shot name="files" alt="按人分文件夹、带主题标签的文件" />

- **里面有什么**:Agent 交付的所有东西(文档、报告、代码文件、图片、视频、PPT),以及员工发给它的文件和链接。
- **可追溯**:每个文件都能追溯到产生它的 Agent、对话或任务。
- **只留最新版**:Agent 修改文件时会覆盖原文件,不会堆出一堆副本。
- **谁能看**:发起这件事的人,以及这个 Agent 的成员。
- **文件夹**:每个人有自己的文件夹。Agent 会把新成果归到合适的文件夹,并打 1~3 个主题标签,方便查找。
- **说一声就行**:Agent 能查找、移动、整理文件和文件夹;你的 SuperAgent 还能替你读取、重命名、改标签和删除。
- 页面里可以**预览**,也可以下载。

文件内容存在哪里由管理员选择:服务器本地,或 S3 兼容的对象存储。见[文件存储](./admin#文件存储)。

## Skills

Skill 是可复用的工作方法:Agent 要遵循的说明,需要的话可以带图片。

<Shot name="skills" alt="个人和公司两级 Skills" />

| 级别 | 谁能用 | 谁能改 |
| --- | --- | --- |
| **公司** | 所有人 | 管理员 |
| **个人** | 仅自己 | 自己 |

- **挂载**到 Agent 上;任务会继承执行它的那个 Agent 的 Skills。
- **按需加载**:Agent 只看到列表,工作需要时才打开某个 Skill,Skills 再多也不会挤占上下文。
- **在对话里**,Agent 可以列出、查看、创建、修改 Skills,以及挂载和卸下。新建的 Skill 不会自动挂上,删除需要你确认。
