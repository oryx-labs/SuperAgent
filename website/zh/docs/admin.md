# 管理与安全

管理后台只有管理员能进。侧边栏:**用户**、**模型**、**分析**,以及**系统设置**(基本设置、连接配置、文件存储)。

## 用户与组织架构

- **预先开通**:只有管理员添加过的人才能登录。用用户名和密码,或用手机号添加。
- **组织架构**:只读展示团队和汇报关系。消息分拣会用到它(你的上级和直属下属的消息更重要)。
- **角色**:管理员管理公司的配置,其他人使用。

## 系统设置

### 基本设置

- 公司全称和简称。
- Agent 的默认模型。
- 公司 Logo,显示在顶部和登录页。
- 浏览器访问用的**对外地址**(经过代理或域名访问时),OAuth 回调会用到。
- 是否开启[模型档位](./models#模型档位-预览)。

## 如何让 AI 用得安全、看得见

- **人来拍板。** 计划等你批准;任务需要你决定时会停下来问;把人邀请进 Agent、删除 Skill,都要点一下确认。
- **权限。** 只有 Agent 的所有者能改它的设定;文件只对相关的人可见;管理后台只对管理员开放。
- **外部的话不能直接驱动操作。** SuperAgent 处理外部消息时,只有只读和收件箱工具。
- **有记录。** 每个 Agent 的运行日志、任务的事件流和花费。
- **密钥。** API Key、Token 和应用 Secret 都加密存储,不会返回给浏览器;传给运行时走环境变量,不出现在命令行里。
- **每次运行单独授权。** 每次 Agent 运行都拿到一个短期凭证来使用 SuperAgent 的工具,范围限定在它为之工作的那个人。

还没做的:企业审批流程,以及隔离 Agent 在服务器上执行的操作。见[路线图](./roadmap)。

## 部署

自托管:发布包(tar 包)或 Docker 镜像(预装了编码 CLI),加 MySQL。也支持 ClickHouse 作为存储。见[快速开始](./getting-started)。
