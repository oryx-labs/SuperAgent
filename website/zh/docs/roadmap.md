# 路线图

SuperAgent 迭代很快。这里列出还没做的,所以其他文档只写今天已经能用的。

## 协作与延续

- **离职交接**:把一个人的 Agent、上下文和文件交给接手的人,在前人的基础上继续。
- **公司级文件夹**:每个人自己的文件夹之外,共享的文件夹。
- **项目的后续**:在分析页按项目统计花费;SuperAgent 在计划里直接建项目。

## 知识

- **公司级知识**:把所有人的工作提炼成全公司都能用的知识,而不只是每个 Agent 自己的记忆。

## 成本

- **模型网关**:所有模型调用都经过 SuperAgent 里的同一个入口,Key 不再交给 Agent,用量在一处统一计量,公司自己的模型网关也可以接在后面。

## 治理与安全

- **企业审批流程**:关键操作接入公司的审批流程。
- **隔离**:每个员工的 Agent 跑在自己的沙箱里(microVM、gVisor 或 Docker),出网经代理,沙箱里没有长期凭证。
- **多机与多公司**:多台机器上的 Worker 由控制面统一调度,一个控制面服务多家公司。见[技术架构](./architecture)。

## 登录与组织

- **更多登录方式**:手机验证码、SSO、微信。目前是用户名和密码。
- **组织架构同步**:从公司的通讯录同步团队和汇报关系。

## 模型与连接

- **更多 CLI 能执行工作**:CodeBuddy、MiniMax Code、Gemini CLI,目前已经可以安装。
- **更多系统**:「连接配置」里接入更多公司应用,方式和 GitHub、Gitee、飞书一样。
