# Agents & collaboration

An agent is a colleague the company keeps. Its setup, memory and the files it produces stay with the company, not with the person who happened to create it.

## Creating an agent

- **Persona** — pick one of 24 built-in characters, or write your own. It shapes how the agent works and talks.
- **Model** — chats use the company's default model, and tasks pick their own; see [how models are chosen](./models#how-models-are-chosen).
- **Skills** — mount [skills](./files#skills) the agent should follow. You can mount any skill you can see: your own and the company's.
- **Avatar and name** — so people can tell agents apart.

## Chatting

- Replies stream as they are written; an agent can have several conversations.
- **Send anything**: files, images and links. They are saved to [Files](./files) and linked to the agent, so the work and its material stay together.
- **Deliverables become files.** When you ask for a document, a report, code, an image or a video, the agent delivers it as a file you'll find in Files, not just text in the chat.
- From a chat an agent can also create [tasks](./tasks) and [automations](./tasks#automation), and use the company's [connectors](./connectors).

## Long-term memory

- Each agent keeps its own memory of what it has learned about its job, and uses it in later conversations.
- Members can read it; the owner can edit it, or ask the agent to distill a conversation into memory.
- Memory is written sparingly: only what is worth keeping.

## Working with colleagues

- **Share Agent: one agent, several people.** Add colleagues as members and work on the same job together. Every member's message moves the work forward, and everyone sees the conversation live.
- **Invite from the chat.** Ask the agent (or your SuperAgent) to bring someone in. It finds the person in the directory and proposes the invitation; the owner confirms it with one click in the conversation. Removing a member takes effect at once.
- **Only the owner changes the setup** (persona, model, skills, memory). Members work with the agent as it is.

## Run log

Every agent has a run log: its sessions, each turn, memory changes, and what a SuperAgent did. The owner can review it. Entries are kept for 30 days.

## To-do

The to-do page is everyone's home page. It gathers what needs you and what your agents finished, from tasks, your SuperAgent and your messages:

<Shot name="todo" alt="The to-do page: what needs you, and what your agents finished" />

| Tab | What's in it |
| --- | --- |
| All | Everything that needs you now |
| To confirm | Decisions an agent is waiting for, e.g. a task paused for your call, a plan to approve |
| To do | Things for you to do yourself, e.g. extracted from your messages |
| Done | Work your agents finished |
| Notices | Things worth knowing |
| Ignored | What you set aside, with a way to bring it back |
| Messages | Messages from Feishu / DingTalk and what your [SuperAgent](./superagent#messages-from-outside) did with each |

The counters at the top show what's open now and how much your agents finished today, this week, this month and in total.
